快速上手：四個步驟

  1. 接通電源並開機以 USB-C 5V 供電，打開機側電源開關。螢幕會先熄滅片刻，數秒後亮起並顯示示範航班。
  2. 查看螢幕底部記下 MAC 後面的 6 位英數；所有密碼均為 HK- 加上這 6 位。
  3. 連接裝置熱點在手機的 Wi-Fi 清單中選擇 AirportDisplay-XXXX（XXXX 為螢幕 MAC 的後 4 位），密碼為 HK-XXXXXX。
  4. 開啟控制台在瀏覽器輸入 http://192.168.4.1/；出現登入視窗時，帳號輸入 admin，密碼輸入 HK-XXXXXX。
水牌會自行開啟 Wi-Fi 熱點，無需互聯網即可完成設定。瀏覽器可能顯示「不安全」警告，原因是裝置使用本機 HTTP 網頁，屬正常情況。
設定一次即可。日後每次開機，水牌都會沿用已儲存的航班資料與背景圖片，離線時仍可正常顯示。

控制台：航班資料

登入後，控制台分為五個區域：航班資料、Wi-Fi 設定、背景圖片、OTA／維護、登入設定。

背景圖片 · Wi-Fi · 登入設定

背景圖片

選擇一個 PNG 或 JPEG，以「水平位置／垂直位置」滑桿移動裁切範圍，然後按 「上載背景圖片」。裝置會自動裁切為 320×212，預覽即為實際效果。

Wi-Fi 設定（可選）

可讓水牌連接您的 Wi-Fi（僅支援 2.4GHz）。設定後螢幕會顯示 STA 與 IP，您可直接以該 IP 開啟控制台。

  • 密碼留空＝不變更現有網絡。
  • 勾選「清除已儲存 Wi-Fi」＝回復僅熱點模式。
  • 即使不連接 Wi-Fi，水牌仍可正常運作。

登入設定

可更改控制台帳號與密碼（最少 8 個字元）。儲存後請以新帳號重新登入。

手機或電腦上的控制台（航班資料頁）

維護與復原

1RST：按一下重新啟動（不會清除設定）
2BOOT：按住約 5 秒＝原廠重設
3電源開關（機側最底，近 USB-C）：ON／OFF

恢復原廠設定

按住機側 BOOT 約 5 秒（螢幕底部會顯示 BOOT 提示），放開後裝置會重新啟動。航班資料、Wi-Fi、背景圖片與登入帳號將全部清除，並回復出廠示範資料。

下載模式（維修／重新刷機用）

按住 BOOT，按一下 RST，然後放開 BOOT，裝置便會進入下載模式。

OTA 韌體更新（進階）

先短按並放開 BOOT 以完成授權（授權有效期 120 秒），然後在「維護工具」上載同型號的 .bin 檔案。

警告：上載錯誤檔案會導致水牌無法開機。如不清楚操作內容，請勿自行更新，並於市集現場尋求協助。

如需使用電腦重新刷機，請參閱封底的 flash station 網址與 QR code。

常見問題

無法連接 AirportDisplay-XXXX？
請靠近水牌，確認手機使用 2.4GHz、關閉 VPN，然後重新開機再試一次。
忘記控制台密碼？
請查看螢幕底部的 MAC 後 6 位，密碼即為 HK- 加上這 6 位。如曾更改而忘記，請執行一次原廠重設。
輸入 192.168.4.1 沒有反應？
請確認手機仍連接水牌的熱點，不要切換至流動數據。
修改設定後螢幕沒有變化？
請按「儲存航班設定」；背景圖片需等待上載完成後才會套用。
上載背景圖片失敗？
僅支援 PNG 或 JPEG。裝置會自動裁切為 320×212，建議使用橫向構圖。
螢幕沒有畫面？
請檢查電源開關與 USB-C 線，並重新開機一次；若仍未顯示，則需要維修。
中文無法顯示？
內建繁體與簡體中文字型。若個別字元顯示為方格，請改用其他語言或常見字詞。
可以用 5GHz Wi-Fi 嗎？
不可以。水牌只支援 2.4GHz；路由器同時廣播兩個頻段時，請選擇 2.4GHz 的那一個。

Quick start: four steps

  1. Power onConnect USB-C 5V power and switch the unit on. The screen stays dark briefly, then shows the demo flight.
  2. Read the screen footerNote the six characters after MAC; every password is HK- plus those six.
  3. Join the device hotspotOn your phone, join AirportDisplay-XXXX (the last four MAC characters) with the password HK-XXXXXX.
  4. Open the consoleOpen http://192.168.4.1/ in a browser and sign in as admin with HK-XXXXXX.
The display runs its own Wi-Fi hotspot, so no internet is needed for setup. A browser warning that the page is "Not secure" is expected: it is served locally over HTTP.
Setup is a one-off. Later starts reuse the saved flight data and background image, and work with no network.

Reading the system band

  • AP: the display is broadcasting its own hotspot and waiting to be configured.
  • STA 192.168.x.x: the display has joined your Wi-Fi and shows its IP address.
  • The artwork in the middle is the replaceable background image; the factory default is shown.
Before any change, the display shows the built-in demo record: CX 548 · 08:55 · JL 7030 · Hong Kong → Tokyo Haneda · Boarding.

Console: flight data

After signing in, the console has five areas: flight data, Wi-Fi settings, background image, OTA / maintenance and login settings.

Field What to enter
Flight number e.g. CX 548
Codeshare e.g. JL 7030, leave blank if none
Departure English, Traditional and Simplified Chinese
Destination English, Traditional and Simplified Chinese
Departure time 24-hour clock, e.g. 08:55
Status e.g. Boarding / 登機中
Display language Traditional Chinese, Simplified Chinese or English; applies immediately

Press "Save flight settings" after editing; the screen updates immediately.

The display has no external flight API, so it shows exactly what you enter: your own flight, a friend's, or an invented boarding flight. Changing the display language applies at once to the screen and the console.

Background image · Wi-Fi · Login settings

Background image

Choose a PNG or JPEG, set the crop with the horizontal and vertical sliders, then press "Upload background image". The device crops it to 320×212; the preview matches the result.

Wi-Fi settings (optional)

The display can join your Wi-Fi network (2.4GHz only). The screen then shows STA and an IP you can use to open the console.

  • A blank password keeps the current network.
  • Tick "Clear saved Wi-Fi" to return to hotspot-only mode.
  • The display works normally without any Wi-Fi connection.

Login settings

Change the console account and password (at least 8 characters). After saving, sign in again with the new account.

Console on a phone (flight data page)

Maintenance and recovery

1RST: press to restart (keeps your settings)
2BOOT: hold about 5 s = factory reset
3Power switch (lowest on the side, by the USB-C): ON/OFF

Factory reset

Hold BOOT for about 5 seconds (the screen footer shows the hint), then release. The display restarts and clears flight data, Wi-Fi, the background image and the console account.

Download mode (service and re-flashing)

Hold BOOT, tap RST, then release BOOT. The display enters download mode.

OTA firmware update (advanced)

Press and release BOOT to authorise an update (valid for 120 seconds), then upload a .bin file for this product under "Maintenance tools".

Warning: uploading the wrong file can leave the display unable to boot. If you are unsure, do not update it yourself; ask us at the market.

To re-flash from a computer, see the flash station address and QR code on the back page.

Frequently asked questions

Cannot find AirportDisplay-XXXX?
Move closer, check the phone is on 2.4GHz, turn off any VPN, then power-cycle and retry.
I forgot the console password.
Read the six characters after MAC at the bottom of the screen: the password is HK- plus those six. If you changed it and forgot, run a factory reset.
192.168.4.1 does not respond.
Check that the phone is still connected to the display's hotspot rather than mobile data.
Nothing changes after I edit the settings.
Press "Save flight settings". A background image is applied only after the upload finishes.
The background upload fails.
Only PNG and JPEG are supported; the device crops to 320×212, so use a landscape picture.
The screen is blank.
Check the power switch and USB-C cable, then restart. If it stays blank, the unit needs service.
Chinese characters do not appear.
Chinese fonts are built in. If a single character shows as a box, try another language or a simpler word.
Can it join a 5GHz network?
No. The display only supports 2.4GHz. If your router broadcasts both bands, pick the 2.4GHz SSID.
