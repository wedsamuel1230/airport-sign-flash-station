3. 私隱聲明（我們收集甚麼）

我們不收集你的個人資料。 本網站沒有帳戶、沒有登記表格、沒有網上付款、沒有廣告，亦沒有 Google Analytics 或任何追蹤工具。我們不會出售或分享任何個人資料。

  • 網站寄存：本網站由 GitHub Pages 提供。GitHub 會自動記錄伺服器日誌（例如 IP 位址、裝置與瀏覽器資料、日期時間、瀏覽頁面），詳見 GitHub 私隱聲明。我們無法存取這些日誌中的個人身分。
  • 刷機頁面（flash station）：該頁會由 jsDelivr CDN 載入 esptool-js 程式庫。載入時你的 IP 位址會傳送給 jsDelivr，詳見 jsDelivr 私隱政策。
  • USB 連接：刷機與設定全程在你的瀏覽器與你的裝置之間直接進行（Web Serial），不會上傳到任何伺服器。
  • 你主動聯絡我們：如你在 GitHub Issues 留言或於市集向我們提供個人資料（例如電郵），我們只會用於回覆與售後支援，並按香港《個人資料（私隱）條例》處理：提供該資料屬自願，用途僅限上述目的，我們不會轉移給第三方作推廣。

4. Cookie 與本機儲存

  • 本網站不設任何 cookie，因此沒有需要同意的 cookie，亦沒有 cookie 橫額。
  • 若你手動切換「深色模式」，我們會在你的瀏覽器 localStorage 記住 theme 這個偏好（僅儲存在你自己的裝置、不會傳送給我們，清除瀏覽器資料即會刪除）。
  • 除此之外我們不會在你的裝置儲存任何資料。
